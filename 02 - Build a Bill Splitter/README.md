 This tool will calculate how much each person owes after adding meal costs and a tip.
 
 This workshop contains 8 steps 👣
 -----------------------------------------------------------------------------------------------------
 ▫ Step 1 : Create a variable named running_total and assign it the value 0.

 ▫ Step 2 : Create a variable named num_of_friends and assign it the value of 4.

 ▫ Step 3 : Create four variables: appetizers set to 37.89, main_courses set to 57.34, desserts set to 39.39, and drinks set to 64.21.

 ▫ Step 4 : Use the += operator once to add appetizers, main_courses, desserts, and drinks to running_total.  Use print() to display the string Total bill so far: followed by a space and the value of running_total.

 ▫ Step 5 : Create a variable named tip and assign it the result of multiplying running_total by 0.25. Use print() to display the string Tip amount: followed by a space and the value of your tip variable.

 ▫ Step 6 : Use the += operator to add the value of tip to your running_total. Use print() to display the string Total with tip: followed by a space and the value of running_total.

 ▫ Step 7 : Create a variable named final_bill and assign it the result of dividing running_total by num_of_friends. Use the print() function to display the string Bill per person: followed by a space and the value of final_bill.

 ▫ Step 8 : Use the round() function to round final_bill to two decimal places and assign the result to a new variable named each_pays. Use print() to display the string Each person pays: followed by a space and your each_pays variable.
